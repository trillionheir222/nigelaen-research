How to read this board

Documentation is not a claim meter.

The board records public visibility and disclosure maturity. It does not measure scientific truth, technical readiness, commercial availability, or the value of confidential work.

One square, one status: each row uses a single colored square beside its label. A protected entry is complete when it is responsibly bounded—not when it reveals more.
