Experimental hybrid computation

FrankenLab

When does combining two ways of processing information actually help? Nigel Patch’s computing lab builds hybrids and tests them against simpler alternatives. Temporal Chimera explores one such question. Can a system distinguish two signals that differ only in the order of their events?

What makes a “creature”?

Patch calls each modular prototype a creature. He starts with existing open-source components and a task that makes their interaction visible. One component might respond to a changing signal. Another might help the system recognize a pattern it has encountered before.

The useful comparison is what happens when a simpler system attempts the same task. If it performs just as well, the lab has learned something about the extra complexity. Patch keeps unsuccessful experiments alongside promising ones, recording the software versions, test conditions, results, and limitations for each run.

Featured experiment

Temporal Chimera

Documented run · November 2026

Temporal Chimera studies the connection between timing and memory. Its task is to classify noisy sequences in which the order of events carries information. A system has to pick out a pattern even when small fluctuations make two examples of it look different.

Patch reports running the hybrid and simpler methods on the same synthetic classification task. The run documents how the prototype behaved on those sequences. A dependable advantage would have to hold across different samples of noisy data.

What should a system remember?

Imagine teaching a system to recognize a new signal, then playing one it knew before. Does it still recognize the old one? FrankenLab asks which details of past experience a system needs to keep, and when a different way of storing them helps it learn something new.
